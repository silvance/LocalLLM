# LocalLLM Airgap Bundle

A self-contained, offline-deployable bundle of:
- The LocalLLM Streamlit app + scripts
- Pre-pulled Ollama models (Granite 4, Gemma 4, Qwen3-Coder-30B, nomic-embed-text)
- Pre-built Chroma RAG index over the configured corpus
- Python wheels for offline `pip install`
- Ollama and Python installers (added manually before transfer)

See `INSTALL.md` for setup instructions.
