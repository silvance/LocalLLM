How to fix
  1. From a terminal: curl {{ ollama_status.configured_url }}/api/tags should return JSON. If it doesn't, Ollama isn't on that URL.
  2. Check what URL ollama list uses — echo $env:OLLAMA_HOST (PowerShell) or echo $OLLAMA_HOST (POSIX). If set, copy that exact value into your .env as OLLAMA_HOST=<value> and restart this server.
  3. If the daemon is on a non-default port, set OLLAMA_HOST=http://127.0.0.1:<port> in .env.
  4. On Windows, prefer 127.0.0.1 over localhost — modern Windows resolves localhost to ::1 but Ollama only binds IPv4.
  5. Run python -m app.cli doctor for a full diagnostic.
